## 0. 체크리스트

아래 질문들에 대해 답변할 수 있다면 해당 포스트는 바로 넘어가도 된다.

- \(\mathcal N(\mu,\sigma^2I)\)의 의미는 무엇인가?
- Gaussian sampling을 \(\mu+\sigma\epsilon\)으로 표현하는 이유는?
- \(q(x_t\mid x_{t-1})\)와 \(q(x_t\mid x_0)\)의 차이는?

---

## 1. Probability Distribution and Gaussian

확률변수 \(x\)의 분포

\[
x \sim p(x)
\]

이는 \(x\)가 확률분포 \(p\)에서 생성되었다는 뜻이다.

<br/>

Diffusion에서는 크게 두 분포를 구분한다.

- \(q\): 데이터에 noise를 추가하는 고정된 forward process
- \(p_\theta\): noise에서 데이터를 복원하는 학습 가능한 reverse process

예를 들어:

\[
q(x_t\mid x_{t-1})
\]

는 \(x_{t-1}\)이 주어졌을 때 한 단계 noisy한 \(x_t\)의 분포이다.

<br/>

## 2. 조건부 확률

\[
p(x\mid y)
\]

는 \(y\)가 주어졌을 때 \(x\)의 분포이다.

<br/>

Diffusion에서 자주 등장하는 세 분포는 다음과 같습니다.

\(q(x_t\mid x_{t-1})\): \(x_{t-1}\)에서 한 단계 noise 추가

\(q(x_t\mid x_0)\): 원본 이미지에서 임의의 timestep으로 바로 이동

\(p_\theta(x_{t-1}\mid x_t)\): 한 단계 denoising

<br/>

* 조건부 분포의 기본 관계 (Bayes’ theorem)

\[
p(x,y)=p(x\mid y)p(y)
\]

\[
p(x\mid y)
=
\frac{p(y\mid x)p(x)}{p(y)}
\]

<br/>

## 3. Gaussian Distribution

* 1차원 가우시안 분포

\[
x\sim\mathcal N(\mu,\sigma^2)
\]

- \(\mu\): 평균
- \(\sigma^2\): 분산
- \(\sigma\): 표준편차

* 다변량 가우시안 분포

이미지는 여러 픽셀로 구성된 벡터이므로 다변량 Gaussian을 사용한다

\[
x\sim\mathcal N(\mu,\Sigma)
\]

<br/>

Diffusion에서는 각 차원에 독립적인 Gaussian noise를 같은 크기로 추가한다고 가정하고, 공분산을 단순하게 설정한다.

\[
\Sigma=\sigma^2 I
\]

<br/>

## 4. Reparameterization


\[
x\sim\mathcal N(\mu,\sigma^2I)
\]

위 분포는 아래와 같이 표현할 수 있다.

\[
\epsilon\sim\mathcal N(0,I),
\qquad
x=\mu+\sigma\epsilon
\]

<br/>

Diffusion에서 아래 형태로 주로 표현한다.

\[
x_t
=
\sqrt{\bar\alpha_t}x_0
+
\sqrt{1-\bar\alpha_t}\epsilon
\]

여기서:

- \(x_0\): 원본 이미지
- \(x_t\): timestep \(t\)에서의 noisy image
- \(\epsilon\): 표준 Gaussian noise
- \(\bar\alpha_t\): 원본 신호가 얼마나 남아 있는지 나타내는 값

즉, \(x_t\)는 원본과 noise의 가중합이다.


### 확인 문제

다음을 말로 설명해보자.

\[
x_t=0.8x_0+0.6\epsilon
\]

답:<br/>
원본 신호의 비중이 0.8이고 noise의 비중이 0.6인 noisy sample을 만든다는 뜻이다. 계수 제곱의 합이 1이므로 전체 분산 규모도 유지된다.
